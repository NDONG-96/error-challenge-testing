# Input data

The clinical datasets used in this study are not included in this repository because they contain patient-related information and are subject to applicable data-protection and institutional restrictions.

The analysis notebook expects the following clinical input datasets in:

`data/input/`

- `all_data_train.csv`
- `all_data_test.csv`
- `input_complet_test.csv`
- `input_partial_test.csv`

The error-challenge campaign dataset is provided separately as:

`campaign_deliveries.csv`

This dataset is used by `figure1_and_tables.py` to evaluate the selected models on the error-challenge campaigns and to generate Supplementary Table S9 and `campaign_detection.csv`.

The clinical datasets and the error-challenge campaign dataset are not publicly distributed through GitHub or Zenodo.

Access to the datasets required to reproduce the analysis can be requested from the authors, subject to the applicable confidentiality, data-protection, and institutional requirements.

Researchers or reviewers who require access to the datasets should contact the corresponding authors through the appropriate channels.
