# Input data

The clinical dataset used in this study is not included in this
repository because it contains patient-related information and is
subject to applicable data-protection and institutional restrictions.

The analysis notebook expects the input dataset at:

`data/input/input.csv`

The dataset is not publicly distributed through GitHub or Zenodo.

For peer review, the complete dataset can be made available to
authorized journal reviewers through a controlled-access mechanism,
subject to the applicable confidentiality, data-protection, and
institutional requirements.

Reviewers who require access to the dataset should contact the
corresponding authors through the journal's peer-review process.
