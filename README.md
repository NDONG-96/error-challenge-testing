# Proton Dose Calibration

This repository contains the analysis code associated with the study on independent verification of the dose calibration coefficient in passive-scattering proton therapy.

## Repository structure

```text
proton-dose-calibration/
├── README.md
├── requirements.txt
├── .gitignore
├── data/
│   └── input/
│       └── README.md
├── notebooks/
│   └── proton_dose_calibration.ipynb
└── results/
    └── figures/
```

## Analysis workflow

The complete analysis is implemented in the Jupyter notebook:

`notebooks/proton_dose_calibration.ipynb`

The notebook includes:

1. Loading of the original dataset.
2. Data cleaning, including the charge threshold criterion.
3. Separation of the training and independent test sets.
4. Analytical inverse power-law modelling.
5. Radial basis function interpolation.
6. Machine-learning model configuration.
7. Definition of relative-error metrics.
8. Five-fold cross-validation.
9. Data transformations.
10. Random Forest, Extra Trees, and XGBoost regression.
11. Hyperparameter grid definition and grid search.
12. Final model selection and retraining.
13. Prediction on the independent test set.
14. Independent test-set evaluation.
15. Comparative analysis of the machine-learning, RBF, and analytical models.
16. Generation of summary tables and figures.

## Input data

The original clinical dataset used in this study is not distributed with this repository.

The analysis notebook expects the input dataset at:

```text
data/input/input.csv
```

To reproduce the analysis, an authorized copy of the dataset must be placed at this location before running the notebook.

The input dataset is not generated by the analysis code.

## Software requirements

The Python dependencies required to run the analysis are listed in:

`requirements.txt`

Install them using:

```bash
python -m pip install -r requirements.txt
```

## Reproducing the analysis

1. Clone or download this repository.
2. Install the dependencies listed in `requirements.txt`.
3. Place the authorized input dataset at `data/input/input.csv`.
4. Open `notebooks/proton_dose_calibration.ipynb`.
5. Run the notebook cells in order.

The notebook contains the preprocessing procedure, model configurations, cross-validation procedure, hyperparameter grids, model fitting, independent test-set evaluation, and comparative analyses used in the study.

## Outputs

The analysis generates model predictions, summary tables, and figures.

Generated results are not required as input to the analysis and can be regenerated by running the notebook.

## Data availability

The clinical input dataset is not publicly distributed with this repository. Only the analysis code and the information required to reproduce the computational workflow are provided.
